Tentatives Capture

Uploads California superior court tentative-ruling PDFs to a GitHub archive.

GitHub connection

Paste a fine-grained Personal Access Token scoped to the target repo, with Contents: Read & Write and Metadata: Read. Generate one at github.com/settings/personal-access-tokens/new. Classic tokens with the repo scope also work.

The token is stored in chrome.storage.local and is readable by anyone with filesystem access to your browser profile. Use a repo-scoped fine-grained token, not a broad classic token.

Bulk scan

When you click Scan all depts in the popup, the extension opens each known landing page for that county in a background tab and waits for it to settle before harvesting PDFs. Bump this up if the court site is slow or renders PDFs after load.

Supported sites

  • www.eldorado.courts.ca.gov/online-services/tentative-rulings/* — El Dorado
  • www.placer.courts.ca.gov/* — Placer
  • contracosta.courts.ca.gov/*, cc-courts.org/* — Contra Costa (iframe + collapsibles)
